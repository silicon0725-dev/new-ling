# 灵（ling）— AI 角色生命模拟器

「灵」是一个桌面端的 AI 角色生命模拟器：你用文字与图片**素材铸造**出独一无二的角色，在与它的**对话**中观察特质自然生长，让它离开对话后在**领地**中自主生活，而它的一切经历都会沉淀为一张由 wgpu 渲染的**成长星图**——力导向图 + 粒子 + 发光效果的动态可视化，记录这个"生命"走过的每一步。

仓库根目录的 `ling.html` 是官网介绍页（重构起点，旧项目代码不迁移）；本仓库是「灵」的 Rust 重构版实现。

## 架构总览

Cargo 工作区按三层拆分，**依赖严格单向（自上而下）**：

```
+-------------------------------------------------------------+
|  ling-app    Slint UI（五页界面） + tokio 异步编排            |
+------------------------------+------------------------------+
                               |  单向依赖
                               v
+-------------------------------------------------------------+
|  ling-render  wgpu 星图渲染器（离屏 RGBA 输出）               |
+------------------------------+------------------------------+
                               |  单向依赖
                               v
+-------------------------------------------------------------+
|  ling-core    领域模型 + rusqlite 持久化                      |
+-------------------------------------------------------------+
```

依赖规则：

- `ling-app → ling-render → ling-core`，只允许自上而下的单向依赖，严禁反向引用；
- `ling-render` 只依赖 `ling-core` 与 wgpu，**不依赖 slint**——渲染层可在无窗口 / 离屏环境独立复用与测试；
- `ling-core` 是纯 Rust 核心库，禁止依赖任何 UI / GPU 框架。

## 各 crate 职责

| Crate | 职责 |
| --- | --- |
| `ling-core` | 领域核心：`character`（角色 / 身份 / 特质：活跃度衰减、休眠唤醒、对话涌现写入）、`memory`（三层记忆引擎：scene → event → arc 逐层聚合与检索）、`world`（领地与世界最小状态，1:72 时间流速）、`ai`（OpenAI 兼容客户端：SSE 流式 + 结构化 JSON，带 SSRF 防护）、`store`（rusqlite(bundled) 持久化：编号迁移 + 全参数绑定）、`starmap`（星图力导向布局模拟：确定性初始化、可收敛） |
| `ling-render` | 星图渲染器：把 `ling-core::starmap` 的模拟结果渲染为力导向图 + 粒子 + 发光效果，以离屏 RGBA 帧输出交给上层 UI 显示 |
| `ling-app` | 应用层：五页 UI（铸造 / 对话 / 领地 / 星图 / 设置）与 LLM 流程编排，基于 Slint 界面 + tokio 异步运行时调度对话、记忆与渲染 |

> 当前进度：`ling-core`、`ling-render`、`ling-app` 均已落地；`cargo build --workspace` 与 `cargo test --workspace` 全量通过。

## 本地运行

环境要求：

- Windows + MSVC 工具链（Visual Studio C++ 生成工具）；
- Rust stable（rustup 默认通道即可）。

运行步骤：

```bash
cargo run -p ling-app
```

应用启动后，进入**设置页**配置 OpenAI 兼容的 LLM 服务：

1. 填写 `baseURL`（任意 OpenAI 兼容服务地址）；
2. 填写 `apiKey`（仅保存在本地，请勿泄露或提交到版本库）；
3. 填写 `model`（模型名）；
4. 点击**连通性测试**，确认服务可达后即可开始铸造角色。

仅构建核心库：`cargo build -p ling-core`。

### 数据与安全约定

- 数据目录：Windows 默认 `%APPDATA%\ling`（可用环境变量 `LING_DATA_DIR` 覆盖），内含 SQLite 数据库 `ling.db`、模型配置 `settings.json` 与全量导出的备份 JSON；
- 模型网关仅接受 `http/https` 且可公网访问的地址（环回 / 私有 / 保留网段会被拒绝，不跟随重定向），校验由 `ling-core::ai` 在每次请求前执行；
- API Key 只保存在本机数据目录，源码、示例与测试中不含任何真实凭据；
- 全部 SQL 经由 `ling-core::store`（含应用层近况表 `app_timeline`），一律静态语句 + 参数绑定；
- 无人工环境可用 `LING_SMOKE_NAV=1 cargo run -p ling-app` 自动巡检六个页面后正常退出，用于「五页可导航、无 panic」验收。

## 路线图与非目标

以下方向**明确列为非目标 / 远期**，当前版本不做、也不承诺时间表：

- **世界铸造**：多领地 / 世界级的编辑与模拟；
- **旅行背包**：角色跨领地移动与随身物品系统；
- **MCP**：Model Context Protocol 工具接入；
- **移动端**：Android / iOS 等平台移植。

近期聚焦：完成 `ling-render` 星图渲染与 `ling-app` 五页 UI 的落地，打磨"素材铸造 → 对话生长 → 领地生活 → 星图沉淀"的核心闭环。
